## ① The idea
A ratio compares two quantities of the **same kind** (convert units first). a : b = a/b.

## ② Formulas
- **Proportion** a : b :: c : d ⇔ ad = bc (extremes × extremes = means × means).
- **Fourth proportional** to a, b, c = bc/a. **Third proportional** to a, b = b²/a. **Mean proportional** = √(ab).
- **Combining ratios:** A : B = 2 : 3, B : C = 4 : 5 → make B the same (LCM 12) → 8 : 12 : 15.
  Formula: A : B : C = (a·c) : (b·c) : (b·d) for A:B = a:b, B:C = c:d.
- **2A = 3B = 4C** → A : B : C = 1/2 : 1/3 : 1/4 → multiply by 12 → 6 : 4 : 3.
- **Dividing x in ratio a : b : c** → shares = x·a/(a+b+c), etc.
- Duplicate ratio of a : b = a² : b²; sub-duplicate = √a : √b; triplicate = a³ : b³.
- Compound ratio of (a:b), (c:d), (e:f) = ace : bdf.

## ③ Worked examples
**Ex 1.** Numbers in 3 : 5; subtract 9 from each → 12 : 23. (3x − 9)/(5x − 9) = 12/23 → 69x − 207 = 60x − 108 → x = 11 → **33, 55**.

**Ex 2.** Salaries 2 : 3, each +4000 → 40 : 57. (2x + 4000)·57 = (3x + 4000)·40 → 114x + 228000 = 120x + 160000 → x = 11333.33 → B = 3x = **₹34000**.

**Ex 3 (coins).** 50 p, 25 p, 10 p coins in number ratio 5 : 9 : 4, total ₹206. Value ratio = 2.5 : 2.25 : 0.4 → sum 5.15 → x = 40 → coins 200, 360, 160.

**Ex 4.** 20% of A = 30% of B = 1/6 of C → A = 5k, B = 10k/3, C = 6k → **15 : 10 : 18**.

**Ex 5 (income-expenditure).** Incomes 4 : 3, expenditures 3 : 2, each saves ₹600. 4x − 3y = 600, 3x − 2y = 600 → x = 600, y = 600 → incomes **₹2400, ₹1800**.
Shortcut for this type: solve the two linear equations directly.

## ⑤ Traps
- Convert units before ratio (3 hours : 1 day = 3 : 24 = 1 : 8).
- Adding the same number to both terms changes a ratio.
