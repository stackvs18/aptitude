## ① The idea
If A finishes a job in n days, A does **1/n** of the job per day. Rates **add** when people work together.

## ② The LCM (units) method — use this for every question
1. Take total work = LCM of all the given days.
2. Each person's efficiency = total work ÷ his days.
3. Add or subtract efficiencies, then divide the work by the combined efficiency.

*Example:* A = 10 days, B = 15 days → work = 30 units; A = 3/day, B = 2/day; together 5/day → **6 days**.

## Formulas
- Together: 1/T = 1/a + 1/b (+ 1/c …) → for two people, T = ab/(a + b).
- If A + B take x days and A alone takes y → B alone = xy/(y − x).
- A + B in x, B + C in y, C + A in z → A + B + C = 2xyz/(xy + yz + zx).
- **A is k times as efficient as B** → A takes 1/k of B's time.
- **Wages** are shared in the ratio of **work done** (= efficiency ratio when they work the same days).
- **M₁D₁H₁/W₁ = M₂D₂H₂/W₂** (men × days × hours per unit of work).
- If A + B together take T days, A alone takes T + a and B alone takes T + b → **T = √(ab)**.

## ③ Worked examples
**Ex 1.** A = 16 days, B = 8 days → LCM 16: A = 1, B = 2 → 16/3 = **5⅓ days**.

**Ex 2.** A + B = 4 days, B = 6 days → A = 4 × 6/(6 − 4) = **12 days**.

**Ex 3.** A + B = 12, B + C = 15, C + A = 20 → LCM 60: (A+B) 5, (B+C) 4, (C+A) 3 → 2(A+B+C) = 12 → A+B+C = 6 → 60/6 = **10 days**. Also: A alone = 6 − 4 = 2/day → 30 days.

**Ex 4.** A is twice as fast as B; together 14 days → efficiencies 2 : 1 → work = 3 × 14 = 42 → A = **21 days**, B = 42 days.

**Ex 5 (someone leaves).** A = 10, B = 15. Together for 3 days, then A leaves. Work 30: A 3, B 2 → in 3 days 15 done → B does the remaining 15 in **7.5 days**.

**Ex 6 (alternate days).** A = 10 days, B = 15 days, working on alternate days starting with A. Work 30: 2-day cycle = 5 units → 6 cycles (12 days) = 30 → **12 days**.

**Ex 7 (wages).** A = 8 days, B = 12 days, total wage ₹200 → efficiencies 3 : 2 → B gets **₹80**.

**Ex 8 (men-women).** 2 men or 3 women do a job in 12 days → 1 man = 1.5 women. How long for 4 men + 3 women? 4M + 3W = 6W + 3W = 9W. 3 women take 12 days → 9 women take **4 days**.

**Ex 9.** A takes twice as long as B or thrice as long as C; together 2 days. A = 6t, B = 3t, C = 2t → (1 + 2 + 3)/6t = 1/t = 1/2 → B = **6 days**.

## ⑤ Traps
- Don't add days! Add **rates**.
- "Portion done by A" = A's efficiency / total efficiency.
