## ① The idea
"A beats B by x m" → when A finishes the race (L), B has run only (L − x). So in the **same time**, distances are in the speed ratio: **A : B = L : (L − x)**.

## ② Vocabulary
- **A gives B a start of x m** → B starts x m ahead (B runs L − x while A runs L).
- **A beats B by t seconds** → B takes t seconds more than A for the full race.
- **"Beats by x m or t s"** → B covers x m in t s → B's speed = x/t.
- **Dead heat** → both finish together.
- **"In a game of 100, A can give B 20 points"** → when A scores 100, B scores 80.

## ③ Worked examples
**Ex 1.** 100 m: A takes 36 s, B 45 s → in 36 s B runs 100 × 36/45 = 80 → A wins by **20 m**.

**Ex 2 (chain).** 1 km: A beats B by 100 m, B beats C by 150 m → A : B = 1000 : 900, B : C = 1000 : 850 → when A = 1000, C = 900 × 0.85 = 765 → A beats C by **235 m**.

**Ex 3 (start → start).** A gives B 50 m and C 69 m in 1 km → B : C = 950 : 931 → in 1000 m C runs 980 → B gives C **20 m**.

**Ex 4 (metres + seconds).** 200 m: A beats B by 35 m or 7 s → B's speed 5 m/s → B's time 40 s → A's time **33 s**.

**Ex 5 (winning post).** A is 5/3 times as fast as B; B gets 80 m start → x/(x − 80) = 5/3 → **x = 200 m**.

**Ex 6 (points).** In 100 points A gives B 20 and C 28 → B : C = 80 : 72 = 100 : 90 → B gives C **10 points**.

## ⑤ Trap
When scaling to a different race length (e.g. 180 m), first get the ratio, then scale: B : C = 90 : 87 → in 180 m, C = 174 → B beats C by 6 m (not 3 m!).
