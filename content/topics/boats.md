## ① The idea
Downstream the river helps (speeds add); upstream it opposes (speeds subtract).

## ② Formulas
B = speed of boat in still water, S = speed of stream.
- **Downstream D = B + S**, **Upstream U = B − S**.
- **B = (D + U)/2**, **S = (D − U)/2**.
- Time upstream = k × time downstream → (B + S) = k(B − S) → B : S = (k + 1) : (k − 1).
- Round trip of distance d: total time = d/(B + S) + d/(B − S).
- Going and returning take total T → d = T(B² − S²)/(2B).

## ③ Worked examples
**Ex 1.** D = 11, U = 5 → B = **8**, S = 3.

**Ex 2.** 32 km down and 14 km up, 6 h each → D = 16/3, U = 7/3 → S = **1.5 km/h**.

**Ex 3.** 7 km up in 42 min → U = 10; S = 3 → B = **13**.

**Ex 4.** Up takes 3× down → B : S = 4 : 2 = 2 : 1. If B = 9⅓ → S = **4⅔**.

**Ex 5.** B = 9, S = 1.5, d = 105 each way → 105/10.5 + 105/7.5 = 10 + 14 = **24 h**.

**Ex 6.** B = 5, S = 1, return trip in 1 h → d = 1 × (25 − 1)/10 = **2.4 km**.
