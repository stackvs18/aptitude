## What it is
An **antonym** is a word with the opposite meaning.

## Examples
| Word | Antonym |
|---|---|
| Ancient | Modern |
| Artificial | Natural |
| Brave | Cowardly |
| Expand | Contract |
| Generous | Stingy |
| Humble | Arrogant |
| Optimist | Pessimist |
| Permanent | Temporary |
| Scarce | Abundant |
| Transparent | Opaque |
| Victory | Defeat |
| Lenient | Strict |
| Barren | Fertile |
| Affluent | Poor |
| Exaggerate | Understate |

## Types
- **Gradable:** opposites on a scale (hot–cold, with warm in between).
- **Complementary:** either one or the other (alive–dead).
- **Relational:** one implies the other (buy–sell, teacher–student).
- Prefix antonyms: happy–**un**happy, possible–**im**possible, legal–**il**legal, regular–**ir**regular.

## Tip
Beware of options that are synonyms. Examiners put them in as traps.
