## Simplification
Reducing an expression to a single value using the correct order of operations.

## Approximation
Rounding numbers to the nearest convenient value (e.g. 49.87 → 50, 1999 → 2000) so the answer can be picked from the options without exact working. Use it when the options are far apart.

## BODMAS rule
**B**rackets → **O**rders/Of (powers, roots, "of") → **D**ivision → **M**ultiplication → **A**ddition → **S**ubtraction. Division and multiplication go left to right; so do addition and subtraction.
Brackets in order: ( ) then { } then [ ]. A bar (vinculum) is solved first.

## Rules for expressions
- **Rule 1:** "of" means multiply, and it comes before ÷ and ×.
- **Rule 2:** solve inside brackets from the innermost outward.
- **Rule 3:** use identities to avoid long multiplication: (a + b)², a² − b², and (a³ + b³)/(a² − ab + b²) = a + b.

## Tips and tricks
- Learn squares to 30, cubes to 15, and the fraction-percent table.
- Use unit digits to eliminate options quickly.
- 999 × 47 = 47000 − 47 = 46953 (base-method tricks).
- *Example:* 18 ÷ 3 × 2 + 4 of 5 = 18 ÷ 3 × 2 + 20 = 6 × 2 + 20 = **32**.
