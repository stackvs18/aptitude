## Terms used in races
- **Race:** contest of speed over a fixed distance. **Course:** the ground; **starting point** and **winning post** (finish).
- **Dead heat:** all reach the finish together.
- **A gives B a start of x m:** B starts x m ahead, so B runs L − x while A runs L.
- **A beats B by x m:** when A finishes, B is x m behind, so in the same time A runs L and B runs L − x.
- **A beats B by t s:** B finishes t seconds after A.
- **Games:** "A can give B 20 points in 100" means when A scores 100, B scores 80.

## Key method
In the same time, distances are in the ratio of speeds: **A : B = L : (L − x)**.
- Chain ratios for three runners: A : B and B : C → A : C.
- "Beats by x m or t s" → B covers x m in t s → B's speed = x/t.

## Solved examples
- 1 km race: A beats B by 100 m, B beats C by 150 m → when A runs 1000, B runs 900 and C runs 900 × 850/1000 = 765 → A beats C by **235 m**.
- 200 m: A beats B by 35 m or 7 s → B's speed 5 m/s → B's time 40 s → A's time **33 s**.
- In a game of 100, A gives B 20 and C 28 → B : C = 80 : 72 = 100 : 90 → B can give C **10 points**.
