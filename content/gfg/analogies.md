## What it is
A pair shows a relationship; find the word, number or figure with the same relationship. Format: **A : B :: C : ?**

## Types
1. **Numerical analogy:** 3 : 27 :: 4 : **64** (cube); 6 : 36 :: 9 : **81** (square); 8 : 4 :: 18 : **9** (half).
2. **Letter/word analogy:**
   - Synonym: Big : Large :: Quick : **Fast**
   - Antonym: Hot : Cold :: Up : **Down**
   - Worker–tool: Carpenter : Saw :: Tailor : **Needle**
   - Worker–place: Doctor : Hospital :: Teacher : **School**
   - Part–whole: Petal : Flower :: Page : **Book**
   - Cause–effect: Fire : Smoke :: Rain : **Flood**
   - Animal–young: Cow : Calf :: Dog : **Puppy**
   - Animal–sound: Lion : Roar :: Snake : **Hiss**
   - Letter shift: ACE : BDF :: GIK : **HJL** (+1 each)
3. **Image-based analogy:** figure 1 changes into figure 2 by a rotation, flip, added line or shading. Apply the same change to figure 3.

## Tips
Make a sentence for the first pair ("A ___ works in a ___"), then test each option with the same sentence.
