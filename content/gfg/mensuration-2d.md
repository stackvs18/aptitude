## Terms
- **Area:** surface covered by a flat shape (square units). **Perimeter:** length of its boundary (units).

## Formulas for 2D shapes
| Shape | Area | Perimeter |
|---|---|---|
| Square (side a) | a² | 4a; diagonal a√2 |
| Rectangle (l, b) | l × b | 2(l + b); diagonal √(l² + b²) |
| Triangle | ½ × base × height | a + b + c |
| Triangle (Heron) | √[s(s−a)(s−b)(s−c)], s = (a+b+c)/2 | a + b + c |
| Equilateral triangle | (√3/4)a² | 3a; height (√3/2)a |
| Right triangle | ½ × base × perpendicular | sum of sides |
| Parallelogram | base × height | 2(a + b) |
| Rhombus | ½ × d₁ × d₂ | 4a |
| Trapezium | ½ × (sum of parallel sides) × height | sum of sides |
| Circle (radius r) | πr² | 2πr |
| Semicircle | πr²/2 | πr + 2r |
| Sector (angle θ) | (θ/360) × πr² | arc = (θ/360) × 2πr |
| Ring (R, r) | π(R² − r²) | — |

## Tips
- If each side scales by k, area scales by k². (Side up 10% → area up 21%.)
- Wheels: distance in one revolution = circumference 2πr.
