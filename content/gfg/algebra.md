## Building blocks
- **Variable:** a letter for an unknown (x, y). **Constant:** a fixed number. **Coefficient:** the number multiplying a variable (3 in 3x).
- **Term:** 3x², −5y. **Expression:** terms joined by + or − (3x² + 2x − 7). **Equation:** two expressions set equal (2x + 3 = 11).

## Rules
- **Commutative:** a + b = b + a; ab = ba.
- **Associative:** (a + b) + c = a + (b + c); (ab)c = a(bc).
- **Distributive:** a(b + c) = ab + ac.
- Whatever you do to one side of an equation, do to the other.

## Operations
- Add/subtract only **like terms** (same variable and power): 3x + 5x = 8x; 3x + 5y stays.
- Multiply powers of the same base by adding exponents: x² · x³ = x⁵.
- Solve linear equations by isolating x: 2x + 3 = 11 → 2x = 8 → x = 4.

## Important identities
- (a + b)² = a² + 2ab + b²
- (a − b)² = a² − 2ab + b²
- a² − b² = (a + b)(a − b)
- (a + b)³ = a³ + b³ + 3ab(a + b)
- (a − b)³ = a³ − b³ − 3ab(a − b)
- a³ + b³ = (a + b)(a² − ab + b²); a³ − b³ = (a − b)(a² + ab + b²)
- (a + b + c)² = a² + b² + c² + 2(ab + bc + ca)
- a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca); so if a + b + c = 0, a³ + b³ + c³ = 3abc.

## Quadratics
ax² + bx + c = 0 → x = [−b ± √(b² − 4ac)]/2a. Sum of roots = −b/a, product = c/a.
