## Ratio
- A **ratio** a : b compares two quantities of the **same kind and unit**: a : b = a/b. a is the antecedent, b the consequent.
- **Properties:** multiplying or dividing both terms by the same non-zero number doesn't change the ratio (2 : 3 = 4 : 6). Adding the same number to both terms does change it.
- **Compound ratio** of a : b and c : d = ac : bd. **Duplicate** = a² : b²; **sub-duplicate** = √a : √b; **triplicate** = a³ : b³.
- **Combining** A : B = 2 : 3 and B : C = 4 : 5: make B equal (LCM 12) → 8 : 12 : 15.

## Proportion
- Four numbers are **in proportion** (a : b :: c : d) when a/b = c/d, i.e. **ad = bc** (product of extremes = product of means).
- **Fourth proportional** to a, b, c = bc/a. **Third proportional** to a, b = b²/a. **Mean proportional** of a and b = √(ab).
- **Properties:** if a/b = c/d then (a + b)/b = (c + d)/d (componendo), (a − b)/b = (c − d)/d (dividendo), (a + b)/(a − b) = (c + d)/(c − d) (componendo–dividendo).

## Types of proportion
- **Direct:** both rise together (y = kx): more items → more cost.
- **Inverse:** one rises as the other falls (xy = k): more workers → fewer days.
- **Continued:** a, b, c are in continued proportion when a : b = b : c, i.e. b² = ac.

## Ratio vs proportion
A ratio compares two quantities. A proportion says two ratios are equal.

## Tricks
- Dividing an amount N in ratio a : b : c → shares N·a/(a+b+c), N·b/(a+b+c), N·c/(a+b+c).
- If 2A = 3B = 4C, then A : B : C = 1/2 : 1/3 : 1/4 = 6 : 4 : 3 (multiply by the LCM).
- If x% of A = y% of B, then A : B = y : x.
