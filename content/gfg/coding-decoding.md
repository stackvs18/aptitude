## What it is
A word or number is converted using a hidden rule. Find the rule from the example and apply it to the question.

## Types
1. **Letter coding:**
   - Shift: CAT → DBU (+1).
   - Reverse: MONKEY → YEKNOM, then shift −1 → XDJMNL.
   - Opposite letters: GOLD → TLOW (each letter ↔ its pair, positions summing to 27).
   - Increasing shift: +1, +2, +3 …
2. **Number coding:** letters → positions (CAT = 3-1-20, or sum 24), or digits given for letters (ROSE = 6821 → read each letter's digit).
3. **Symbol coding:** letters or digits are replaced by symbols (@, #, $) following conditions ("if the first letter is a vowel, swap the first and last codes").
4. **Sentence/word coding:** 'pit na sa' = 'you are good', 'na ja tod' = 'they are bad' → the common word **na** = are.

## Tricks
- Write the positions of both words and subtract to see the shift.
- Check whether the code is reversed before looking for shifts.
- In sentence coding, compare two sentences at a time to find the common word.
- In substitution coding ("water is called food …"), answer with the **code name**, not the real one.
