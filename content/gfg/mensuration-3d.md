## Terms
- **Volume:** space inside (cubic units). **Curved/lateral surface area (CSA/LSA):** the sides only. **Total surface area (TSA):** all faces.

## Formulas for 3D shapes
| Solid | Volume | Surface area |
|---|---|---|
| Cube (a) | a³ | TSA 6a²; LSA 4a²; diagonal a√3 |
| Cuboid (l, b, h) | lbh | TSA 2(lb + bh + hl); LSA 2h(l + b); diagonal √(l²+b²+h²) |
| Cylinder (r, h) | πr²h | CSA 2πrh; TSA 2πr(r + h) |
| Cone (r, h, slant l) | ⅓πr²h | CSA πrl; TSA πr(l + r); l = √(r² + h²) |
| Sphere (r) | (4/3)πr³ | 4πr² |
| Hemisphere (r) | (2/3)πr³ | CSA 2πr²; TSA 3πr² |
| Frustum (R, r, h) | ⅓πh(R² + r² + Rr) | CSA π(R + r)l |
| Prism | base area × height | LSA = base perimeter × height |
| Pyramid | ⅓ × base area × height | LSA = ½ × base perimeter × slant height |

## Tips
- If all dimensions scale by k: surface area × k², volume × k³.
- **Melting and recasting:** the volume stays the same. Number of small solids = big volume ÷ small volume.
- 1 m³ = 1000 litres; 1 litre = 1000 cm³.
