## What it is
Find the pair with the same relationship as the given pair. Format: **A : B :: C : D**.

## Common relationships
| Relationship | Example |
|---|---|
| Synonym | Happy : Joyful |
| Antonym | Light : Dark |
| Part–whole | Wheel : Car |
| Worker–tool | Painter : Brush |
| Worker–product | Author : Book |
| Cause–effect | Virus : Disease |
| Degree/intensity | Warm : Hot |
| Function/purpose | Pen : Write |
| Category/type | Rose : Flower |
| Animal–young | Lion : Cub |
| Animal–home | Bee : Hive |
| Country–capital | India : New Delhi |
| Male–female | Horse : Mare |

## Tricks
- Make a precise sentence linking the first pair, then test each option with the same sentence.
- Keep the **order** the same: "Cub : Lion" is the reverse of "Lion : Cub".
- If two options fit, make the sentence more specific.
