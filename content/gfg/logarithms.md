## Definition
If **aˣ = N**, then **logₐ N = x** (a > 0, a ≠ 1, N > 0). The log is the power you raise the base to.
- Exponential → log: 2⁵ = 32 → log₂ 32 = 5.
- Log → exponential: log₁₀ 1000 = 3 → 10³ = 1000.

## Types
- **Common log:** base 10 (log x). **Natural log:** base e ≈ 2.718 (ln x).

## Rules
| Rule | Formula |
|---|---|
| Product | log(mn) = log m + log n |
| Quotient | log(m/n) = log m − log n |
| Power | log(mⁿ) = n log m |
| Base change | logₐ m = log m / log a |
| Reciprocal | logₐ b = 1/log_b a |
| Special | logₐ a = 1, logₐ 1 = 0, a^(logₐ m) = m |

## Log and antilog tables
Tables give log values of numbers (and antilog turns logs back into numbers). For MCQs, remember **log 2 ≈ 0.3010, log 3 ≈ 0.4771, log 5 ≈ 0.6990, log 7 ≈ 0.8451**.
*Example:* log 8 = 3 log 2 = 0.9030. Number of digits in 2⁶⁴ = ⌊64 × 0.3010⌋ + 1 = **20**.

## Log function and graph
y = logₐ x is defined only for x > 0, passes through (1, 0), rises when a > 1 and falls when 0 < a < 1.
