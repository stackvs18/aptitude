## Concepts
- If A does a job in n days, A's **one-day work = 1/n**.
- Work done = rate × time. Rates of people working together **add**.
- **Efficiency** is inversely proportional to time: twice as efficient → half the time.
- **Wages are shared in the ratio of work done** (equal days → ratio of efficiencies).

## Formulas
- A and B together: **T = ab/(a + b)**. Three people: 1/T = 1/a + 1/b + 1/c.
- A + B take x days and A alone y days → B alone = xy/(y − x).
- A + B, B + C, C + A take x, y, z → all three together: 2xyz/(xy + yz + zx).
- **M₁D₁H₁/W₁ = M₂D₂H₂/W₂** (men × days × hours ÷ work).

## Shortcut: the LCM (units) method
1. Total work = LCM of the days. 2. Each person's efficiency = work ÷ their days. 3. Add efficiencies and divide.
*Example:* A = 20 days, B = 30 days → work 60 units; A = 3/day, B = 2/day → together 5/day → **12 days**.

## Wages example
A takes 8 days, B 12 days, and they earn ₹200 together → efficiencies 3 : 2 → A gets **₹120**, B **₹80**.

## Common twists
- Someone leaves partway: count the units done together, then finish the rest with whoever stays.
- Alternate days: work out one 2-day cycle, then count full cycles.
- Men and women/boys: convert everyone to one unit using the given equivalence (2 men = 3 women).
