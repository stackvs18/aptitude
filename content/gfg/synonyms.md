## What it is
A **synonym** is a word with the same or nearly the same meaning. Pick the option closest in meaning.

## Examples
| Word | Synonym |
|---|---|
| Abundant | Plentiful |
| Benevolent | Kind |
| Candid | Frank |
| Diligent | Hard-working |
| Eminent | Distinguished |
| Frugal | Thrifty |
| Gregarious | Sociable |
| Hostile | Unfriendly |
| Lucid | Clear |
| Obsolete | Outdated |
| Pragmatic | Practical |
| Prudent | Wise |
| Reluctant | Unwilling |
| Tranquil | Calm |
| Vivid | Bright |

## Tips
- Use the word in a sentence, then swap each option in.
- Use roots and prefixes: "bene" = good, "mal" = bad, "bio" = life.
- Watch the part of speech: a noun's synonym is a noun.
