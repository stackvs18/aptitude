## Number System
- Divisibility: 3, 9 → digit sum; 4 → last 2; 8 → last 3; 11 → alternate-sum difference 0/11k.
- Unit digit: cycle of 4. Trailing zeros of n! = Σ ⌊n/5ᵏ⌋.
- 1 + … + n = n(n + 1)/2; first n odd = n²; first n even = n(n + 1).

## HCF/LCM
- Product of 2 numbers = HCF × LCM. Same remainder → HCF of differences. Remainder r → LCM + r.
- Fractions: HCF = HCF(num)/LCM(den); LCM = LCM(num)/HCF(den).

## Average
- Sum = Avg × n. Newcomer = new avg + n_old × increase. Replacement = old + n × change.
- Avg speed (equal distances) = 2xy/(x + y).

## Percentage
- r% more ⇒ other is r/(100 + r) × 100 % less. Successive: a + b + ab/100.
- Price ↑ r% ⇒ consumption ↓ r/(100 + r) × 100 %. Population: P(1 + r/100)ⁿ.

## Profit & Loss
- Gain % on C.P. S.P. = C.P.(100 ± g)/100. C.P. of x = S.P. of y ⇒ (x − y)/y × 100.
- False weight: error/(true − error) × 100. Same S.P., ±x% ⇒ loss x²/100 %.
- Discounts d₁, d₂ ⇒ d₁ + d₂ − d₁d₂/100.

## Simple Interest
- SI = PRT/100. Doubles in T yrs ⇒ R = 100/T. n times ⇒ R = 100(n − 1)/T.

## Ratio
- a : b :: c : d ⇒ ad = bc. 4th prop = bc/a; 3rd prop = b²/a; mean prop = √(ab).

## Alligation
- Cheaper : Dearer = (d − m) : (m − c). Replacement: x(1 − y/x)ⁿ. Milkman gains g% ⇒ water : milk = g : 100.

## Partnership
- Profit ∝ capital × time.

## Time & Work / Pipes / Chain
- LCM units method. Two together = ab/(a + b). Fill a, leak b ⇒ ab/(b − a).
- M₁D₁H₁/W₁ = M₂D₂H₂/W₂. T = √(ab) for T + a and T + b.

## TSD / Trains / Boats / Races
- km/h × 5/18 = m/s. Opposite ⇒ add speeds; same ⇒ subtract.
- Train: pole → L; platform → L + P; two trains → L₁ + L₂.
- B = (D + U)/2, S = (D − U)/2. Up takes k × down ⇒ B : S = (k + 1) : (k − 1).
- A beats B by x in race L ⇒ A : B = L : (L − x).

## Calendar
- Ordinary year 1 odd day, leap 2. 100 yrs → 5, 200 → 3, 300 → 1, 400 → 0.
- Month odd days: 31-day → 3, 30-day → 2, Feb → 0 (leap 1). 0 = Sunday.

## Clock
- θ = |30H − 5.5M|. Coincide at 60H/11 min past H. Mirror = 11:60 − time.
